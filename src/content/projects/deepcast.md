DeepCast was a startup that built a <nobr>semantic-search</nobr> powered podcast transcript platform for podcast fans and marketing tools for podcasters.

I built search flows for users to search for podcast excerpts on topics that interested them using semantic search. I also enjoyed building image generation tools that podcasters used to share their content on social platforms quickly with canvas tooling and asynchronous infrastructure.
